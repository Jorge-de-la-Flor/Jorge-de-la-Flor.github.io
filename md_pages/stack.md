# Stack Tecnológico

Mi stack está orientado al **desarrollo de sistemas**, desde infraestructura cloud y software distribuido hasta firmware y sistemas ciberfísicos.

Trabajo principalmente con **Python y Rust**, complementados con C/C++ y herramientas especializadas para ingeniería de lenguajes, generación de código, sistemas embebidos y cloud.
